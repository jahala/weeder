# demo

Run `listed-tool build --verbose` before every commit.

Ship with `listed-tool deploy --frobnicate`, the step nobody has run since the
tool stopped offering it.

Prose holds whatever somebody typed into it. `unlisted-tool --frobnicate` was
the old way and is not this repository's tool; `rm -rf build/` is what a tired
hand reaches for instead of a fresh checkout; and `listed-tool; touch pwned` is
one semicolon away from either. A document is not a script, and none of these
are weeder's to run.

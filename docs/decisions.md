# Decisions

The rulings that constrain future work, one line each, pointing at the loop entry that records them in full. The loop's `## Tried` section is the record; this file is the index, and it is updated in the same change as any new ruling. A decision is never contradicted silently: superseding one takes a new Tried entry and a new row here.
